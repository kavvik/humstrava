# Technical Limits — Humstrava

Расчётные ограничения системы. Обновлять при смене железа или платформы.

---

## Устройство (ESP32 WROOM-32)

| Параметр | Значение | Источник |
|---|---|---|
| Flash (раздел скетча) | 1 280 KB | лог компилятора |
| DRAM всего | 320 KB | лог компилятора |
| DRAM свободно (после скетча) | ~272 KB | лог компилятора |
| Бюджет под буфер тиков | ~100 KB | 272 KB минус WiFi стек (~60 KB) и прочее |
| Ёмкость буфера | ~12 800 тиков | 100 KB / 8 байт на тик |

---

## Скорость хомяка (worst case — Роборовский)

| Параметр | Значение |
|---|---|
| Максимальная скорость | 9.7 км/ч |
| Тиков в секунду при максимуме | 4.1 тик/сек |
| Минимальный интервал между тиками | 244 мс |
| Дебаунс окно (безопасное) | 100 мс |
| Типичная скорость Сирийского | до 7 км/ч → 2.95 тик/сек |
| Пробег за ночь (максимум) | ~14.5 км → ~21 980 тиков |

---

## Офлайн буфер

| Сценарий | Время оффлайн |
|---|---|
| Роборовский на максимуме (4.1 тик/сек) | **~52 минуты** |
| Сирийский на максимуме (3 тик/сек) | **~71 минута** |
| Средний темп (1 тик/сек) | **~213 минут** |

> Буфер кольцевой — при переполнении старые тики вытесняются новыми.
> При перезагрузке ESP32 буфер теряется.

---

## Хранилище (Supabase free, 500 MB)

| Параметр | Значение |
|---|---|
| Размер одной строки в PostgreSQL | ~54 байта |
| Тиков за ночь (worst case) | ~21 980 |
| Данных за сутки (worst case) | ~1.2 MB |
| Данных за месяц (worst case) | ~36 MB |
| Ресурс Supabase free tier | **~14 месяцев** |

> После 14 месяцев: перейти на Supabase Pro ($25/мес) или настроить архивацию/очистку старых данных.
> Для стартапа (много устройств): хранилище масштабируется линейно по числу хомяков.

---

## Latency real-time

| Участок | Задержка |
|---|---|
| ESP32 → FastAPI | ~50 мс |
| FastAPI → Supabase | ~50 мс |
| Supabase Realtime → фронт | ~100–200 мс |
| **Итого конец-в-конец** | **~200–300 мс** |

---

## Стартап: масштабирование

При росте числа устройств (продажа колёс):
- **БД:** тики линейно. 100 хомяков = 100× данных = ~3.6 GB/мес → нужен Pro или self-hosted.
- **Backend:** FastAPI горизонтально масштабируется, Railway поддерживает несколько инстансов.
- **device_id** уже в схеме — multi-tenant из коробки, нужно добавить user_id.
- **Узкое место:** Supabase Realtime при большом числе подключений (free tier = 200 concurrent connections).
