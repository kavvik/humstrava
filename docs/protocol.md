# ESP32 → Backend Protocol

## Формат батча

ESP32 собирает тики локально и отправляет батч раз в ~1 секунду.

```json
{
  "d": "hamster-wheel",
  "ticks": [1748945201123, 1748945201456, 1748945201789]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `d` | string | device_id — идентификатор устройства |
| `ticks` | int[] | Unix timestamp каждого тика в миллисекундах |

## Почему абсолютные timestamp'ы, а не delta

- Каждый тик независим — потеря батча не ломает контекст
- Парсинг тривиальный
- Трафик несущественен (~50 байт/сек при активном беге)
- Максимальная гибкость при интерпретации

## Endpoint

```
POST /ticks
Content-Type: application/json
```

Ответ:
- `200 OK` — батч принят
- `4xx` — ошибка валидации

## Частота отправки

Раз в 1 секунду, если есть тики. Если тиков нет — не отправлять.
