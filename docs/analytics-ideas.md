# Analytics Ideas — Humstrava

Что можно вычислять из таблицы `ticks`. Всё это доступно из MVP — никаких дополнительных данных не нужно.

Каждый тик = 1 оборот = 0.6597 м. Сессия = непрерывный бег с gap < 60 сек.

---

## 🐹 Линза хозяина — "что делает мой хомяк"

Простые факты, которые хочется знать каждый день.

| Метрика | Как считать |
|---|---|
| Дистанция сегодня / за неделю / за месяц | COUNT(ticks) × 0.6597 |
| Активное время сегодня | сумма длительностей всех сессий |
| Количество сессий сегодня | количество групп тиков с gap > 60 сек |
| Текущая скорость (real-time) | тиков за последние 3 сек × 0.6597 × 3.6 |
| Когда последний раз бегал | MAX(tick_ms) |
| Самая длинная сессия за всё время | |
| Личные рекорды | макс. дистанция за день, макс. скорость, макс. сессия |
| Streak: сколько дней подряд бегал | consecutive days с хотя бы одним тиком |
| Самые активные дни недели | GROUP BY day_of_week |
| В какое время суток обычно бегает | GROUP BY hour — гистограмма активности |

## 🔬 Линза учёного — "паттерны и аномалии"

Интересно наблюдать за поведением как за данными.

| Метрика | Что показывает |
|---|---|
| Циркадный ритм | в какие часы суток пик активности (хомяки ночные) |
| Распределение скоростей | гистограмма — как быстро обычно бегает, есть ли "крейсерская" скорость |
| Распределение длительностей сессий | большинство сессий короткие или длинные? |
| Паузы между сессиями | сколько времени отдыхает между забегами |
| Тренд активности | скользящее среднее дистанции за 7/30 дней — растёт, падает, стабильно |
| Аномальные дни | дни с активностью значительно ниже или выше среднего |
| Сезонность | активнее летом или зимой? |
| Интенсивность сессии | средняя скорость внутри одной сессии (разгоняется или замедляется) |

## ❤️ Линза health-трекера — "активность как здоровье"

Смотреть на хомяка как Apple Health смотрит на человека.

| Метрика | Аналог у людей |
|---|---|
| Activity Score за день (0–100%) | % от личного среднего | кольца активности |
| Тренд здоровья | активнее или менее активен последние 7 дней vs предыдущие 7 | HealthKit тренды |
| Inactive streak | сколько дней не бегал подряд — тревожный сигнал | streak в Fitness |
| Базовая линия (personal average) | среднее за последние 30 дней — точка отсчёта | VO2 max baseline |
| Восстановление | активность на следующий день после очень активного дня | HRV recovery |
| Ночная активность (%) | хомяк ночной — какой % активности приходится на 20:00–06:00 | sleep score |
| Возраст активности | как активность сравнивается с "нормой для породы" | fitness age |

## 📊 Дашборд MVP — приоритет

Что показывать на главном экране в первую очередь (по убыванию ценности):

1. **Сегодня:** дистанция + активное время + количество сессий
2. **Real-time:** скорость прямо сейчас (обновляется при каждом тике)
3. **График за неделю:** столбики дистанции по дням
4. **Последняя активность:** X часов назад / сейчас бежит
5. **Личный рекорд:** макс. дистанция за день (и когда был)

## 💡 Что потребует дополнительных данных (не MVP)

- Сравнение с другими хомяками — нужен multi-tenant
- Корреляция с температурой в комнате — нужен датчик температуры
- Вес хомяка — пассивное взвешивание через load cell под основанием колеса (HX711 + ~$5), или ручной ввод. Подробнее: [health-tracker-wheel.md](health-tracker-wheel.md)
- Ветеринарные события (болезнь, стресс) — нужен ручной лог
